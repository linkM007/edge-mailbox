# 验证与审查记录

日期：2026-11-09（Asia/Shanghai）。Node.js v22.20.0，Windows。本地套件 27 项测试通过，涵盖以下内容。

| 范围 | 已验证 |
| --- | --- |
| 任务输入 | 额外字段、路径逃逸、目标与资源 origin、缺少代理拒绝 |
| 代理 | 本地 CONNECT 拒绝后失败，无直连回退 |
| SSH | 本地真实 SSH 服务器，通过 CONNECT 完成握手与命令；错误指纹拒绝；同一测试在 workerd 打包版本通过 |
| D1 | 原子领取、并发、幂等冲突、过期、容量、租约、清理、旧结果覆盖阻断 |
| 浏览器 | 资源代理调用、迟到会话关闭、截图结果大小、预览转义与禁止覆盖 |
| Worker | 打包运行、代理拒绝、Cron 记录失败，直接 fetch 测试夹具调用数为零 |
| 云端 HTTP | 部署后通过配置代理取得 IP 检测响应 |
| 云端浏览器 | Browser Run 截图、渲染正文与链接；IP 检测页面与 HTTP 返回一致的代理出口 |
| 云端异步 | D1/Cron 浏览任务 succeeded，截图随结果存储并可取回 |

审查修复：浏览资源预算串行化，防止并发超支；SSH 动态导入后补充取消检查；离线预览使用转义与 CSP；SSH Wasm 改为静态模块；workerd 加密兼容性固定为 AES-CTR + SHA-256 HMAC；截图与凭据文件被 Git 忽略。

依赖审计在交付前运行，结果是当时数据库的快照。它不表示 tunnelfetch 已经过外部密码学审计。

尚未验证用户实际服务器的 SSH 登录与该代理的目标 22 放行情况；云端 SSH_TARGETS 默认空。任意网站的反爬策略、登录页面、复杂 SPA、长连接和全面浏览器兼容性不在已验收范围内。新目标应按部署文档逐个验证。
